How it works

Navneet's phone sends its GPS coordinates to a private Netlify Function every 30 seconds. The function stores the latest point in Netlify Blobs. This public page reads that point every 15 seconds. No login is needed to view it; only the private broadcaster has the update token.

Location accuracy depends on the phone's GPS, network conditions and battery settings. If the signal becomes stale, the map keeps the last known point instead of pretending that a human has magically stopped existing.
